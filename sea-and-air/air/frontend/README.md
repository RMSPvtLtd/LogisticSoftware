# Raaziq frontend

React + TypeScript + Vite + Tailwind CSS + shadcn/ui. See the [project root README](../README.md)
for full setup instructions, the page list, and the design system.

```bash
npm install
npm run dev     # http://localhost:5173, proxies /api to the backend on :8000
npm run build   # type-check + production bundle
npm run lint    # oxlint
```
